## Task List

### T-001: Verify Expo Go compatibility and scaffold the project

**Depends on:** Design approval, Tasks approval
**Req IDs:** REQ-001, REQ-002, REQ-003, NFR-003

**Description:**
Before scaffolding, re-confirm that the current Expo Go app on the App Store
and Play Store still supports SDK 57. If Expo Go has advanced and no longer
supports SDK 57, raise a spec amendment before proceeding. Do not assume.

Once confirmed, scaffold the project using the official template:

```sh
npx create-expo-app@latest vybe --template default@sdk-57
```

If the template name differs (e.g. the SDK 57 template key has changed),
verify the correct template name from `https://docs.expo.dev/router/introduction`
and document the actual command used.

**Acceptance criteria:**
- [ ] Expo Go current SDK version confirmed against official docs; result
      documented in task output
- [ ] `npx create-expo-app@latest vybe --template default@sdk-57` (or verified
      equivalent) runs without errors
- [ ] `package.json` contains `"expo": "~57.x.x"` or equivalent SDK 57 version
- [ ] `npx expo start` launches Metro without errors on Windows 11
- [ ] Directory structure matches or is reconciled with the design (document
      any template-vs-design divergence)

**Affected files:**
- `package.json`, `package-lock.json`
- `app.json`
- `tsconfig.json`
- `src/app/_layout.tsx` (or `app/_layout.tsx` — whichever the template produces)
- `src/app/index.tsx` (or `app/index.tsx`)

### T-008: Apply WCAG 2.1 AA accessibility to shell elements

**Depends on:** T-005
**Req IDs:** REQ-007, NFR-005

**Description:**
Apply the accessibility requirements from design Section 8 to the implemented
screens:

1. Create `src/theme.ts` with colour constants used in the shell. Confirm that
   text/background contrast ratios meet WCAG 2.1 AA (4.5:1 for normal text).
   Use a contrast checker tool (e.g. https://webaim.org/resources/contrastchecker/)
   and document the values chosen.
2. Ensure `SampleDataBadge` has `accessibilityRole="text"` and no `onPress`.
3. Ensure the "Go to home" link on the not-found screen has:
   - An `accessibilityLabel` (e.g. `"Go to home"`)
   - A minimum touchable area of `44 × 44` points
4. Run `npm run lint` and confirm no a11y rule violations (exit code 0).

**Acceptance criteria:**
- [ ] `src/theme.ts` exists with documented colour tokens
- [ ] Contrast ratio for primary text is ≥ 4.5:1 (document the exact ratio in
      task completion notes)
- [ ] `SampleDataBadge` has `accessibilityRole="text"` and no `onPress`
- [ ] Not-found "Go to home" link has `accessibilityLabel` and
      `minHeight: 44` / `minWidth: 44` style applied
- [ ] `npm run lint` exits with code 0

**Affected files:**
- `src/theme.ts`
- `src/components/SampleDataBadge.tsx`
- `src/app/+not-found.tsx`
